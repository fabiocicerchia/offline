📴 offline

A Linux sandbox wrapper that runs a program with its network access fully isolated.

Namespaces (user/net/mount/PID/IPC/UTS) cut off every interface, route, and DNS path; capability dropping and a seccomp filter deny the network syscalls too. Two Go dependencies, single-file source, no daemon.

Build & run
git clone https://github.com/fabiocicerchia/offline
cd offline && make build
./offline curl https://example.com   # fails — no network in the sandbox

requires: pkg-config libseccomp-dev
